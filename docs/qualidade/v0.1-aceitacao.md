# Aceitação da v0.1

Revisão integrada: `59838c6`, em 12 de outubro de 2026. Node.js 24.21.0 e npm 11.19.0.

## Evidências reutilizadas

- `npm run check`: passou na integração.
- `npm run build`: passou na integração.
- `npm test`: 343 testes unitários passaram na tarefa 10.
- `npm run test:integration`: 117 testes passaram na tarefa 10.
- `npm run test:e2e`: 63 testes passaram, 21 em cada motor Chromium, Firefox e WebKit, sem testes pulados, inesperados ou instáveis. O executor usou HTTPS local, CA descartável, PostgreSQL com UID/GID do proprietário dos segredos, reinício, publicação, recuperação e indisponibilidade do banco.
- `npm run performance:measure`: orçamento essencial de 102.149/102.400 bytes e gráfico adicional de 56.282/61.440 bytes; o relatório bruto fica em `artifacts/performance-v0.1.json`.
- O Chrome também comprovou a recuperação do chunk do gráfico após 404→200 sem nova consulta de preços, e os controles nativos de seleção/data foram mantidos.

## Limites declarados

As cinco navegações sob 400 kbit/s, 200 kbit/s, RTT de 800 ms, CPU 4×, metas de 10/15/18 segundos e p95 de dez consultas com `EXPLAIN (ANALYZE, BUFFERS)` ainda não foram medidos neste ambiente. O medidor registra esses campos como `unmeasured`; não há aprovação implícita.

Também não foram inferidos Safari, Edge, aparelhos físicos ou ocupação de IndexedDB em outros motores a partir dos três motores Playwright do executor.

## Operação e segurança

A CA local é criada no projeto Compose efêmero e removida com seus contêineres, rede e volumes identificados. O host não recebe alteração persistente de confiança. Segredos locais permanecem `0600`; volumes PostgreSQL existentes com outra identidade exigem migração explícita e não sofrem `chown` automático.

Licença pública, tag e visibilidade da v0.2 continuam fora desta entrega.
